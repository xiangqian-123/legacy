本作的战斗是动态近战系统，彻底告别了前两作的潜行压制。核心思路：**招架制造眩晕 → 踢击/连招输出 → 专注攻击清场**。这一页把机制拆清楚。

## 基础操作与判定

| 动作 | 说明 |
|---|---|
| 攻击 | 基础剑击，可连段 |
| **招架 Parry** | 时机正确可弹开攻击并造成眩晕；**黄色攻击**可招架，**红色攻击**初期只能闪避 |
| **闪避 Dodge** | 双击闪避键触发二段闪避（需点出 Hero's Step 技能） |
| **踢击 Kick** | 连段第二脚可推动**未眩晕**的敌人，配合悬崖/危险地形秒杀 |
| **投掷 Throw** | 拾取场景中的投掷物攻击敌人，命中后接连招 |

## 专注攻击 Focus Attack

本作战斗的核心资源系统：

- **自动解锁，不消耗技能点**
- 通过攻击/招架/闪避积攒**专注槽 Focus Gauge**
- 满后释放**大范围横扫**，命中多个近身敌人
- 💡 不必留给 Boss——被围时收益最大，回转也很快

## 敌人攻击判定（关键）

| 攻击类型 | 颜色 | 应对 |
|---|---|---|
| 普通攻击 | 无/白 | 招架或闪避 |
| 重型攻击 | 黄 | 可招架 |
| 不可格挡攻击 | 红 | 初期只能闪避；点出 Aegean Deflect 精通后可招架 |

> 红攻招架精通对 Brute 重型敌人的质变效果，是招架流 build 的核心价值。

## 投掷物与环境

战斗场景中散落着可拾取的投掷物（陶罐、器物等）。点出 **Fated Cast 命定投掷**技能后，可以把投掷物挂在腰间储存，按 R3 随时发射——相当于自带的远程手段。

## 战斗流派速览

| 流派 | 核心技能 | 思路 |
|---|---|---|
| 招架流 | Aegean Deflect + Echo's Return | 完美招架→眩晕翻倍→抓人掷向敌群群体眩晕 |
| 闪避流 | Hero's Step + Fated Cast | 二段闪避拉扯→投掷物消耗→连招收尾 |
| 专注流 | Sica 短剑 + Focus Rush | 击杀回充专注槽，专注技连发 |

## 忒修斯闪回战斗（注意）

部分闪回段落操控忒修斯 Theseus，他拥有**独立的战斗节奏和专注攻击**，但 Sophia 的技能升级**不继承**。依赖红攻招架的玩家换人后要重新适应——先用闪避观察节奏。
