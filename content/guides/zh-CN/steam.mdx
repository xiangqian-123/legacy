## 买 Steam 还是 Game Pass？

- **Xbox Game Pass 订阅用户**：本作**首日入库**，PC Game Pass / 主机 Game Pass 均可游玩，还支持 Xbox Play Anywhere（一次购买，主机+PC 双平台）

- **PS5**：只此一家的 DualSense 手柄体验（PS4 没有本作）
- Epic Games Store 同步上架

> 提示：首发期 Steam 同时在线人数与《安魂曲》峰值持平——大量玩家实际通过 Game Pass 游玩，Steam 曲线不能代表全部热度。
