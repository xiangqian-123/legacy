本作技能树的货币是 **Resonance Points 共鸣点数**。核心结论先说：**先点 Hero's Step（生存）和 Aegean Deflect（招架），点数随时可免费洗点，不用纠结。**

## Resonance 点数机制

| 项目 | 说明 |
|---|---|
| 获取方式一 | 环境中发光的**橙色贝壳状收集物**（部分在主线，部分藏角落） |
| 获取方式二 | 特定剧情战斗后**自动发放**（不可错过） |
| 总量 | 全游戏共 **200 点** |
| 点满所需 | **165 点**（容错 35 点） |
| 洗点 | Skills 菜单随时**免费洗点**，无惩罚 |
| ⚠️ 继承规则 | 点数**不通过章节选择继承**；重读章节会把总数重置为当时数值 |

> 最大的坑：点数不能像护符那样通关后补拿。见一个捡一个，别攒到通关后。

## 五大技能详解与优先级

| 技能 | 效果 | 优先级 |
|---|---|---|
| **Aegean Deflect 爱琴海格挡** | 完美招架眩晕伤害翻倍。精通①：**可招架红色攻击**（对 Brute 重型敌质变）② 招架后下一次剑击附加伤害 | 高 |
| **Hero's Step 英雄步伐** | 双击闪避触发**二段闪避**，带无敌帧，拉开距离重新站位 | 高（新手首选） |
| **Echo's Return 回响返还** | 抓住攻击者**掷向周围敌人**造成群体眩晕。基础版仅对普通攻击生效（黄/红攻击需精通） | 中 |
| **Bullbreaker Kick 破牛踢** | 踢击连段第二脚可推动**未眩晕**敌人。破盾兵 + 地形（悬崖/危险物）秒杀 | 中 |
| **Fated Cast 命定投掷** | 可将拾取的投掷物**挂在腰间储存**，之后按 R3 发射 | 低（QoL） |

## 三条 Build 路线

**均衡流**（推荐新手）
Aegean Deflect（红攻招架精通）→ Hero's Step → Echo's Return → Bullbreaker Kick / Fated Cast

**招架流**（激进）
Aegean Deflect → Echo's Return → Hero's Step → Bullbreaker Kick

**闪避流**（稳健）
Hero's Step → Echo's Return → Aegean Deflect → Fated Cast

## 技能 × 武器 × 护符联动

- **专注流**：Sica 短剑（Focus Rush 击杀回充专注槽）+ 提升专注保留的护符 → 专注技连发
- **Boss 流**：Khopesh 镰状剑（Deep Bleed 持续伤害）打 Boss
- **招架流**：Xiphos 双刃剑（Parry Break 招架眩晕大增，代价无法格挡）+ 扩大招架窗口的臂环护符
