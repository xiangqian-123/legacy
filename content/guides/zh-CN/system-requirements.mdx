以下是 Resonance: A Plague Tale Legacy 的官方 PC 配置需求（来自 Steam 商店页）。好消息是：本作优化表现出色，社区实测反馈普遍为「开箱即流畅」，120Hz 屏幕下性能模式可跑约 80 FPS。

## 最低配置（1080p / 低画质 / 30 FPS）

| 项目 | 需求 |
|---|---|
| 系统 | Windows 10/11 64 位 |
| 处理器 | AMD Ryzen 3 3100 / Intel Core i3-12100 |
| 内存 | 16 GB RAM |
| 显卡 | 6 GB VRAM：AMD Radeon RX 5500 XT / Nvidia GeForce GTX 1060 |
| DirectX | Version 12 |
| 存储 | 75 GB 可用空间（**必须 SSD**） |

## 推荐配置（1080p / Ultra / 60 FPS）

| 项目 | 需求 |
|---|---|
| 系统 | Windows 10/11 64 位 |
| 处理器 | AMD Ryzen 5 5600X / Intel Core i5-12400F |
| 内存 | 16 GB RAM |
| 显卡 | 8 GB VRAM：AMD Radeon RX 6700 XT / Nvidia GeForce RTX 3060 Ti |
| DirectX | Version 12 |
| 存储 | 75 GB 可用空间（**必须 SSD**） |

## 额外要求（官方备注）

- 必须使用 **SSD 固态硬盘**
- CPU 需要 **4 核 8 线程**起步
- GPU 需支持 **DX12.1 / Shader Model 6.6**

## 实机性能参考（社区反馈）

- OLED 电视/显示器玩家普遍给出系列最强画面评价
- 120Hz 显示器实测性能模式约 **80 FPS**，画质细节不缩水
- 对比前作《安魂曲》首发（需要调设置、进新区域有加载卡顿），本作首发即流畅
- Steam 页面标注支持 HDR

> 提示：具体帧数表现以实际硬件和驱动版本为准。
