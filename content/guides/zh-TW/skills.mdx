本作技能樹的貨幣是 **Resonance Points 共鳴點數**。核心結論先說：**先點 Hero's Step（生存）和 Aegean Deflect（招架），點數隨時可免費洗點，不用糾結。**

## Resonance 點數機制

| 專案 | 說明 |
|---|---|
| 獲取方式一 | 環境中發光的**橙色貝殼狀收集物**（部分在主線，部分藏角落） |
| 獲取方式二 | 特定劇情戰鬥後**自動發放**（不可錯過） |
| 總量 | 全遊戲共 **200 點** |
| 點滿所需 | **165 點**（容錯 35 點） |
| 洗點 | Skills 選單隨時**免費洗點**，無懲罰 |
| ⚠️ 繼承規則 | 點數**不透過章節選擇繼承**；重讀章節會把總數重置為當時數值 |

> 最大的坑：點數不能像護符那樣通關後補拿。見一個撿一個，別攢到通關後。

## 五大技能詳解與優先順序

| 技能 | 效果 | 優先順序 |
|---|---|---|
| **Aegean Deflect 愛琴海格擋** | 完美招架眩暈傷害翻倍。精通①：**可招架紅色攻擊**（對 Brute 重型敵質變）② 招架後下一次劍擊附加傷害 | 高 |
| **Hero's Step 英雄步伐** | 雙擊閃避觸發**二段閃避**，帶無敵幀，拉開距離重新站位 | 高（新手首選） |
| **Echo's Return 迴響返還** | 抓住攻擊者**擲向周圍敵人**造成群體眩暈。基礎版僅對普通攻擊生效（黃/紅攻擊需精通） | 中 |
| **Bullbreaker Kick 破牛踢** | 踢擊連段第二腳可推動**未眩暈**敵人。破盾兵 + 地形（懸崖/危險物）秒殺 | 中 |
| **Fated Cast 命定投擲** | 可將拾取的投擲物**掛在腰間儲存**，之後按 R3 發射 | 低（QoL） |

## 三條 Build 路線

**均衡流**（推薦新手）
Aegean Deflect（紅攻招架精通）→ Hero's Step → Echo's Return → Bullbreaker Kick / Fated Cast

**招架流**（激進）
Aegean Deflect → Echo's Return → Hero's Step → Bullbreaker Kick

**閃避流**（穩健）
Hero's Step → Echo's Return → Aegean Deflect → Fated Cast

## 技能 × 武器 × 護符聯動

- **專注流**：Sica 短劍（Focus Rush 擊殺回充專注槽）+ 提升專注保留的護符 → 專注技連發
- **Boss 流**：Khopesh 鐮狀劍（Deep Bleed 持續傷害）打 Boss
- **招架流**：Xiphos 雙刃劍（Parry Break 招架眩暈大增，代價無法格擋）+ 擴大招架視窗的臂環護符
