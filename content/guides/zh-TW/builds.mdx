本作沒有職業系統，Build 就是「技能加點順序 × 武器 × 護符」的組合。三條主流路線如下，選一條照著配。

## 路線一：均衡流（推薦新手）

**技能順序**：Aegean Deflect（點滿紅攻招架精通）→ Hero's Step → Echo's Return → Bullbreaker Kick / Fated Cast

- **武器**：Falchion 彎刀（暴擊後傷害）或 Kopis 反刃刀（連段眩暈）
- **護符**：Beads（減弓箭手命中）+ Arm Bands（擴大招架視窗）
- **適合**：第一次玩、想穩紮穩打的玩家

## 路線二：招架流（激進）

**技能順序**：Aegean Deflect → Echo's Return → Hero's Step → Bullbreaker Kick

- **武器**：**Xiphos 雙刃劍**（Parry Break 招架眩暈大增，代價無法格擋）+ Khopesh 鐮狀劍打 Boss
- **護符**：Arm Bands（擴大招架視窗，核心）
- **適合**：喜歡高風險高回報、招架熟練的玩家

## 路線三：閃避流（穩健）

**技能順序**：Hero's Step → Echo's Return → Aegean Deflect → Fated Cast

- **武器**：Sica 短劍（Focus Rush 擊殺回專注槽）
- **護符**：Pierced Coins（專注槽機率保留充能）+ Trinkets（機率免疫致命一擊）
- **適合**：喜歡拉扯、專注技連發的玩家

## 三條路線速查

| 路線 | 核心技能 | 主武器 | 思路 |
|---|---|---|---|
| 均衡流 | Aegean Deflect + Hero's Step | Falchion / Kopis | 招架→眩暈→踢擊輸出 |
| 招架流 | Aegean Deflect + Echo's Return | Xiphos | 完美招架→眩暈翻倍→抓人擲群 |
| 閃避流 | Hero's Step + Echo's Return | Sica | 二段閃避拉扯→專注技連發 |

## 關鍵提醒

- 隨時**免費洗點**，三條路線可以都試試，找到手感再定
- ⚠️ 操控忒修斯 Theseus 的閃回戰鬥裡，**Sophia 的技能升級不繼承**，紅攻招架不可用，先閃避適應節奏
- 招架流拿 Xiphos 後**無法格擋**，只能靠招架，手殘慎用
