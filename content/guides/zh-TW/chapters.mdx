Resonance: A Plague Tale Legacy 共 **14 章**（13 章主線 + 1 章尾聲）。本頁是完整流程攻略的入口，逐章列出收集數量、關鍵謎題與 Boss。

> ⚠️ **重要提醒**：Resonance Points 共鳴點數**不能通關後補**（章節選擇不繼承），必須一週目見一個撿一個，點滿技能需 165 點。詳見[共鳴點數攻略](/zh-TW/guide/resonance-points)。

## 章節速覽（關鍵點）

| 章節 | 關鍵點 |
|---|---|
| Ch1 Blood Ties | 童年序章；獲得 Rusty Sword（初始刀） |
| Ch2 Felons | 獲得 Falchion；⚠️ 木偶劇成就（看完整場） |
| Ch3 Those Before Us | ⚠️ 烏龜成就（海灘轉身看烏龜）；護符密集開端 |
| Ch4 From Hell It Rose | 三符號/反射鏡/迷宮/尖刺/公牛鏡 5 個謎題；獲得 Kopis |
| Ch5 Desolation It Wrought | 四符號試煉（**收集最多章，40 處**）；獲得 Greek Sword |
| Ch6 What Lies Beneath | 怪物追逐；獲得 Sica |
| Ch7 Death It Sowed | 黑神廟顱骨門謎題；獲得 Khopesh（Boss 利器） |
| Ch8 Resonance | 純劇情章，無收集品 |
| Ch9 Night Has Come | 米諾斯宮殿；獲得 Broken Spear |
| Ch10 Parallel Paths | 代達羅斯工坊 + 門謎題；獲得 Xiphos |
| Ch11 Patera | 光束/曲柄謎題 |
| Ch12 Fading Light | 戰事收束 |
| Ch13 As One | 最終章；Minotaur 彌諾陶洛斯 Boss |
| Ch14 What Remains | 尾聲；無收集品 |

## 章節選擇注意事項

- 刀劍、文物、護符、忒修斯迴響**可通關後章節選擇補拿**（見[全收集攻略](/zh-TW/guide/collectibles)）
- 共鳴點數**不繼承**，通關後補不了
- 章節選擇介面顯示每章已收集數，方便定位漏項
