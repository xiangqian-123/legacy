以下是 Resonance: A Plague Tale Legacy 的官方 PC 配置需求（來自 Steam 商店頁）。好訊息是：本作最佳化表現出色，社羣實測反饋普遍為「開箱即流暢」，120Hz 螢幕下效能模式可跑約 80 FPS。

## 最低配置（1080p / 低畫質 / 30 FPS）

| 專案 | 需求 |
|---|---|
| 系統 | Windows 10/11 64 位 |
| 處理器 | AMD Ryzen 3 3100 / Intel Core i3-12100 |
| 記憶體 | 16 GB RAM |
| 顯示卡 | 6 GB VRAM：AMD Radeon RX 5500 XT / Nvidia GeForce GTX 1060 |
| DirectX | Version 12 |
| 儲存 | 75 GB 可用空間（**必須 SSD**） |

## 推薦配置（1080p / Ultra / 60 FPS）

| 專案 | 需求 |
|---|---|
| 系統 | Windows 10/11 64 位 |
| 處理器 | AMD Ryzen 5 5600X / Intel Core i5-12400F |
| 記憶體 | 16 GB RAM |
| 顯示卡 | 8 GB VRAM：AMD Radeon RX 6700 XT / Nvidia GeForce RTX 3060 Ti |
| DirectX | Version 12 |
| 儲存 | 75 GB 可用空間（**必須 SSD**） |

## 額外要求（官方備註）

- 必須使用 **SSD 固態硬碟**
- CPU 需要 **4 核 8 執行緒**起步
- GPU 需支援 **DX12.1 / Shader Model 6.6**

## 實機效能參考（社羣反饋）

- OLED 電視/顯示器玩家普遍給出系列最強畫面評價
- 120Hz 顯示器實測效能模式約 **80 FPS**，畫質細節不縮水
- 對比前作《安魂曲》首發（需要調設定、進新區域有載入卡頓），本作首發即流暢
- Steam 頁面標註支援 HDR

> 提示：具體幀數表現以實際硬體和驅動版本為準。
