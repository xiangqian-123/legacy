卡關了？這一頁把所有謎題的**快速解法**（Quick Solution）按章節整理，直接抄答案。想了解謎題機制原理，見每章攻略頁。

> 本作謎題核心就兩類：**光束反射**（用球照鏡子/底座）和**符號對齊**（看牆上符號轉基座/跳地板）。掌握套路後都不難。

## 你卡在哪一章？

本作有獨立謎題的章節集中在 **Ch4、Ch5、Ch7、Ch10、Ch11**（其餘章節無獨立謎題，直接跑劇情）：

- [第 4 章 From Hell It Rose](/zh-TW/guide/chapter-4-from-hell-it-rose) — 三符號 / 反射鏡 / 迷宮 / 尖刺 / 公牛鏡
- [第 5 章 Desolation It Wrought](/zh-TW/guide/chapter-5-desolation-it-wrought) — 門謎題 / 聖甲蟲地板 / 雕像門 / 鏡房
- [第 7 章 Death It Sowed](/zh-TW/guide/chapter-7-death-it-sowed) — 黑神廟顱骨門 / 光謎題
- [第 10 章 Parallel Paths](/zh-TW/guide/chapter-10-parallel-paths) — 門謎題（三基座 + 6 符號）
- [第 11 章 Patera](/zh-TW/guide/chapter-11-patera) — 光束 / 曲柄 / 透鏡

## 按謎題型別

- **光線/光束謎題**：用球照鏡子、底座反射光 → Ch4 反射鏡、Ch10 門謎題、Ch11 光束
- **球體/三色光謎題**：旋轉球的三色光對齊寶石 → Ch5 門謎題、Ch7 光謎題
- **符號/符文謎題**：看牆上符號轉基座/跳地板 → Ch4 三符號、Ch5 聖甲蟲地板
- **英雄墓謎題**：三色光開墓取刀劍 → Ch5 Greek Sword、Ch6 Sica、Ch7 Khopesh、Ch10 Xiphos

## 全部謎題（按章節）

## Ch4 From Hell It Rose（出自地獄）

### 三符號謎題（開門）
用球照基座，看地面藍線連到牆上的符號，旋轉 3 個基座顯示對應符號。
**答案（左到右）：Y - C - ↑**

### 反射鏡謎題
站地板盤讓光出現，依次反射：
**左反射鏡 → 右反射鏡 → 前左反射鏡 → 前右反射鏡 → 門符號**

### 迷宮謎題（光符號）
**左 =「O」/ 右 =「I」**

### 尖刺陷阱
- 平臺 1：左 - 左 - 左
- 平臺 2：右 - 中（跳過去）- 中
- 尖刺牆：互動左側第三個牆槽

### 公牛鏡謎題
地面白色符號（紅底）兩兩成對，鏡子照牆上對應符號：
- 第 1 對（鈴鐺 + T）：右鏡照前左牆第 1 圖示，左鏡照後右牆第 3 圖示
- 第 2 對（反 S + 三角）：左鏡照前右牆第 3 圖示，右鏡照前左牆第 4 圖示
- 公牛放下手後，照手環得新符號「h」「w」：左鏡照前右牆第 4，中鏡照前右牆第 1

## Ch5 Desolation It Wrought（荒蕪）

### 門謎題（第一扇門）
互動房間中央底座，站右地板盤，用球旋轉三色光對齊門上寶石。

### 聖甲蟲地板符號（骰子門）
按地面 5 符號提示跳安全平臺，跳錯即死：
**圓點(2) - 克拉肯(3) - 圓點(3) - 花(2) - 克拉肯(2) - 圓點(2) - 克拉肯(1 左跳)**

### 雕像門謎題（三次試煉）
站屋頂光柱照到的地板盤，用球三色光對齊門上寶石：
- 第 1 次：紅 = 左雕像頭盔 / 綠 = 中 / 藍 = 右雕像手
- 第 2 次：綠 = 頂 / 藍 = 底 / 紅 = 右雕像眼
- 第 3 次：先照前右灰塵露齒輪，用齒輪讓 Leni 頂住，跳臺後對齊右牆

### 鏡房謎題（線上 O 門）
- 紅 = 照最右鏡 → 照柱右
- 藍 = 左鏡 → 後下鏡 → 中間鏡 → 柱左
- 綠 = 後右鏡 → 柱背

## Ch7 Death It Sowed（死亡播種）

### 黑神廟顱骨門
用球照門看綠點提示按壓順序：
**最右顱骨 → 右數第 2 → 最左 → 左數第 2**

### 黑神廟光謎題
站光裡照牆看藍圖示顱骨，按它移動光；底座轉鏡到中位，站地板盤對齊：
**綠 = 中鏡 / 紅 = 左鏡 / 藍 = 右鏡**

## Ch10 Parallel Paths（平行之路）

### 門謎題（三基座 + 6 符號）
1. 點亮瀑布洞鏡（轉中間輪順時針）
2. 依次反射到門
3. Faro 照光後站地板盤，看綠色金屬片顯藍圖示
4. 走到光中石碑，用球顯 6 符號，移動門上紅/綠/藍水晶對齊

## Ch11 Patera（帕特拉）

### 光束謎題
**右槓桿鬆開讓 Faro 接手，再拉左槓桿**融化灰塵。

### 曲柄謎題
推重物到槓桿造光罩 → 拉槓桿轉光到第 2 曲柄 → 轉曲柄到底。

### 最後的透鏡
站電梯等 Faro 抬起，蹲行躲石化敵人，用球燒鏈上灰塵，推曲柄到底。
