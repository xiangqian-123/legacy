## 買 Steam 還是 Game Pass？

- **Xbox Game Pass 訂閱使用者**：本作**首日入庫**，PC Game Pass / 主機 Game Pass 均可遊玩，還支援 Xbox Play Anywhere（一次購買，主機+PC 雙平臺）
- **Steam 買斷**：想要成就係統、卡片徽章、長期離線收藏的玩家選 Steam
- **PS5**：只此一家的 DualSense 手柄體驗（PS4 沒有本作）
- Epic Games Store 同步上架

> 提示：首發期 Steam 同時線上人數與《安魂曲》峰值持平——大量玩家實際透過 Game Pass 遊玩，Steam 曲線不能代表全部熱度。
