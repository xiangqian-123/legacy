Here are the official PC requirements for Resonance: A Plague Tale Legacy (from the Steam store page). The good news: optimization is excellent, and community reports are mostly "smooth out of the box," with performance mode running ~80 FPS on 120Hz displays.

## Minimum (1080p / Low / 30 FPS)

| Component | Requirement |
|---|---|
| OS | Windows 10/11 64-bit |
| Processor | AMD Ryzen 3 3100 / Intel Core i3-12100 |
| Memory | 16 GB RAM |
| GPU | 6 GB VRAM: AMD Radeon RX 5500 XT / Nvidia GeForce GTX 1060 |
| DirectX | Version 12 |
| Storage | 75 GB free (**SSD required**) |

## Recommended (1080p / Ultra / 60 FPS)

| Component | Requirement |
|---|---|
| OS | Windows 10/11 64-bit |
| Processor | AMD Ryzen 5 5600X / Intel Core i5-12400F |
| Memory | 16 GB RAM |
| GPU | 8 GB VRAM: AMD Radeon RX 6700 XT / Nvidia GeForce RTX 3060 Ti |
| DirectX | Version 12 |
| Storage | 75 GB free (**SSD required**) |

## Additional Notes (Official)

- **SSD required**
- CPU needs **4 cores / 8 threads** minimum
- GPU must support **DX12.1 / Shader Model 6.6**

## Real-World Performance (Community)

- OLED TV/monitor players overwhelmingly rate it the series' best-looking game
- On a 120Hz display, performance mode hits roughly **80 FPS** without visual compromise
- Compared to Requiem's launch (needed tweaks, loading stutters in new areas), this one is smooth from day one
- The Steam page lists HDR support

> Note: exact frame rates depend on your hardware and driver version.
