Resonance: A Plague Tale Legacy has **14 chapters** (13 story chapters + 1 epilogue). This page is the hub for the full walkthrough, listing collectible counts, key puzzles and bosses chapter by chapter.

> ⚠️ **Important**: Resonance Points **cannot be farmed after the credits** (they don't carry over via chapter select). You must grab every one on your first run — maxing all skills requires 165. See the [Resonance Points guide](/en/guide/resonance-points).

## Chapter Quick Reference

| Chapter | Key points |
|---|---|
| Ch1 Blood Ties | Childhood prologue; get the Rusty Sword |
| Ch2 Felons | Get the Falchion; ⚠️ Theater Enthusiast (watch the full puppet show) |
| Ch3 Those Before Us | ⚠️ Sea You Later (turn around for the turtle); charm run begins |
| Ch4 From Hell It Rose | 5 puzzles (three-symbol / mirror / maze / spikes / bull mirror); get the Kopis |
| Ch5 Desolation It Wrought | Four-symbol trials (**most collectibles, 40**); get the Greek Sword |
| Ch6 What Lies Beneath | Creature chase; get the Sica |
| Ch7 Death It Sowed | Black Temple skull door; get the Khopesh (boss killer) |
| Ch8 Resonance | Pure story chapter, no collectibles |
| Ch9 Night Has Come | Minoan palace; get the Broken Spear |
| Ch10 Parallel Paths | Daedalus' workshop + door puzzle; get the Xiphos |
| Ch11 Patera | Light beam / crank puzzles |
| Ch12 Fading Light | The war winds down |
| Ch13 As One | Final chapter; Minotaur boss |
| Ch14 What Remains | Epilogue; no collectibles |

## Chapter Select Notes

- Blades, artefacts, charms and Theseus Echoes **can be collected post-game via chapter select** (see [All Collectibles](/en/guide/collectibles))
- Resonance Points **do not carry over** and cannot be topped up after the credits
- The chapter-select screen shows each chapter's collected count, making it easy to find what you missed
