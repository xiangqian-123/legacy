The game has **275 collectible items**: 8 blades + 37 artefacts + 30 charms + 200 Resonance Points (with the 5 Theseus Echoes also counted among the charms).

## Five Collectible Entries

| Type | Count | Retroactive via chapter select? | Guide |
|---|---|---|---|
| **Resonance Points** | 200 | ⚠️ **No** | [View guide](/en/guide/resonance-points) |
| **Blades** | 8 | ✅ Yes | [View guide](/en/guide/blades) |
| **Artefacts** | 37 | ✅ Yes | [View guide](/en/guide/artefacts) |
| **Charms** | 30 | ✅ Yes | [View guide](/en/guide/charms) |
| **Theseus Echoes** | 5 | ✅ Yes | [View guide](/en/guide/theseus-echoes) |

> ⚠️ **The only thing you can't collect retroactively is Resonance Points**: they don't carry over through chapter select, so you must gather 165 (to max skills) within a single run — otherwise the "Like A Warrior" achievement requires a fresh save.

## Chapter-Select Retroactive Rules

| Item | Rule |
|---|---|
| Charms | Collectible; the select screen shows progress |
| Blades | Collectible; redo the Hero Tomb puzzle in the chapter |
| Artefacts | Collectible; listed in order in the menu |
| Theseus Echoes | Collectible (shaped like pierced-coin bowls) |
| Resonance Points | ⚠️ Reset to the chapter's starting value — unreliable |

## Suggested Collection Flow

1. **First run**: play normally, grab every point you see (target 165), score 1 kill with each new blade
2. **Post-game**: use chapter select to collect charms, artefacts, blades and echoes (locate gaps via each guide)
3. **Blades**: return to the matching chapter and redo the Hero Tomb puzzle
4. **Finally**: confirm points ≥165 (if short, replay the relevant chapter)
