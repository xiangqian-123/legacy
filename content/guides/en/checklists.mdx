## 2. 100% Collection Checklist

| Category | Count | Retroactive? | Guide |
|---|---|---|---|
| Resonance Points | 200 (165 to max) | ⚠️ **No** | [Per-chapter locations](/en/guide/resonance-points) |
| Blades | 8 | ✅ Yes | [All Blades](/en/guide/blades) |
| Artefacts | 37 | ✅ Yes | [All Artefacts](/en/guide/artefacts) |
| Charms | 30 | ✅ Yes | [All Charms](/en/guide/charms) |
| Theseus Echoes | 5 | ✅ Yes | [All Echoes](/en/guide/theseus-echoes) |

> ⚠️ **The only non-retroactive one is Resonance Points**: reach 165 within one run or "Like A Warrior" needs a fresh save. The other 4 categories can all be collected post-game.

## 3. Platinum / All-Achievement Checklist (36)

| Category | Count | Notes | Guide |
|---|---|---|---|
| Story | 14 | Auto-unlocked for completing chapters | [Achievement list](/en/guide/achievements) |
| Collectible | 6 | Hoarder / Plunderer / Superstitious / Like A Warrior / In The Name Of My Kin / Adaptable | [Achievement list](/en/guide/achievements) |
| Combat | 12 | Need deliberate setup (Untouchable / Overboard etc.) | [Achievement list](/en/guide/achievements) |
| Misc | 4 | Sea You Later / Theater Enthusiast / Close Call / Unpredictable | [Achievement list](/en/guide/achievements) |

**Platinum route**:
1. First run: grab every point (target 165), score 1 kill per new blade
2. Post-game chapter select for charms/blades/artefacts/echoes
3. Combat achievements: return to suitable scenes and set them up deliberately
4. Misc (Sea You Later / Theater Enthusiast): watch for them on the first run
