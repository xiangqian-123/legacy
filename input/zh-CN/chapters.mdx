Resonance: A Plague Tale Legacy 共 **14 章**（13 章主线 + 1 章尾声）。本页是完整流程攻略的入口，逐章列出收集数量、关键谜题与 Boss。

> ⚠️ **重要提醒**：Resonance Points 共鸣点数**不能通关后补**（章节选择不继承），必须一周目见一个捡一个，点满技能需 165 点。详见[共鸣点数攻略](/zh-CN/guide/resonance-points)。

## 章节速览（关键点）

| 章节 | 关键点 |
|---|---|
| Ch1 Blood Ties | 童年序章；获得 Rusty Sword（初始刀） |
| Ch2 Felons | 获得 Falchion；⚠️ 木偶剧成就（看完整场） |
| Ch3 Those Before Us | ⚠️ 乌龟成就（海滩转身看乌龟）；护符密集开端 |
| Ch4 From Hell It Rose | 三符号/反射镜/迷宫/尖刺/公牛镜 5 个谜题；获得 Kopis |
| Ch5 Desolation It Wrought | 四符号试炼（**收集最多章，40 处**）；获得 Greek Sword |
| Ch6 What Lies Beneath | 怪物追逐；获得 Sica |
| Ch7 Death It Sowed | 黑神庙颅骨门谜题；获得 Khopesh（Boss 利器） |
| Ch8 Resonance | 纯剧情章，无收集品 |
| Ch9 Night Has Come | 米诺斯宫殿；获得 Broken Spear |
| Ch10 Parallel Paths | 代达罗斯工坊 + 门谜题；获得 Xiphos |
| Ch11 Patera | 光束/曲柄谜题 |
| Ch12 Fading Light | 战事收束 |
| Ch13 As One | 最终章；Minotaur 弥诺陶洛斯 Boss |
| Ch14 What Remains | 尾声；无收集品 |

## 章节选择注意事项

- 刀剑、文物、护符、忒修斯回响**可通关后章节选择补拿**（见[全收集攻略](/zh-CN/guide/collectibles)）
- 共鸣点数**不继承**，通关后补不了
- 章节选择界面显示每章已收集数，方便定位漏项
