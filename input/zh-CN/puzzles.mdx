## 全部谜题（按章节）

## Ch4 From Hell It Rose（出自地狱）

### 三符号谜题（开门）
用球照基座，看地面蓝线连到墙上的符号，旋转 3 个基座显示对应符号。
**答案（左到右）：Y - C - ↑**

### 反射镜谜题
站地板盘让光出现，依次反射：
**左反射镜 → 右反射镜 → 前左反射镜 → 前右反射镜 → 门符号**

### 迷宫谜题（光符号）
**左 =「O」/ 右 =「I」**

### 尖刺陷阱
- 平台 1：左 - 左 - 左
- 平台 2：右 - 中（跳过去）- 中
- 尖刺墙：互动左侧第三个墙槽

### 公牛镜谜题
地面白色符号（红底）两两成对，镜子照墙上对应符号：
- 第 1 对（铃铛 + T）：右镜照前左墙第 1 图标，左镜照后右墙第 3 图标
- 第 2 对（反 S + 三角）：左镜照前右墙第 3 图标，右镜照前左墙第 4 图标
- 公牛放下手后，照手环得新符号「h」「w」：左镜照前右墙第 4，中镜照前右墙第 1

## Ch5 Desolation It Wrought（荒芜）

### 门谜题（第一扇门）
互动房间中央底座，站右地板盘，用球旋转三色光对齐门上宝石。

### 圣甲虫地板符号（骰子门）
按地面 5 符号提示跳安全平台，跳错即死：
**圆点(2) - 克拉肯(3) - 圆点(3) - 花(2) - 克拉肯(2) - 圆点(2) - 克拉肯(1 左跳)**

### 雕像门谜题（三次试炼）
站屋顶光柱照到的地板盘，用球三色光对齐门上宝石：
- 第 1 次：红 = 左雕像头盔 / 绿 = 中 / 蓝 = 右雕像手
- 第 2 次：绿 = 顶 / 蓝 = 底 / 红 = 右雕像眼
- 第 3 次：先照前右灰尘露齿轮，用齿轮让 Leni 顶住，跳台后对齐右墙

### 镜房谜题（线上 O 门）
- 红 = 照最右镜 → 照柱右
- 蓝 = 左镜 → 后下镜 → 中间镜 → 柱左
- 绿 = 后右镜 → 柱背

## Ch7 Death It Sowed（死亡播种）

### 黑神庙颅骨门
用球照门看绿点提示按压顺序：
**最右颅骨 → 右数第 2 → 最左 → 左数第 2**

### 黑神庙光谜题
站光里照墙看蓝图标颅骨，按它移动光；底座转镜到中位，站地板盘对齐：
**绿 = 中镜 / 红 = 左镜 / 蓝 = 右镜**

## Ch10 Parallel Paths（平行之路）

### 门谜题（三基座 + 6 符号）
1. 点亮瀑布洞镜（转中间轮顺时针）
2. 依次反射到门
3. Faro 照光后站地板盘，看绿色金属片显蓝图标
4. 走到光中石碑，用球显 6 符号，移动门上红/绿/蓝水晶对齐

## Ch11 Patera（帕特拉）

### 光束谜题
**右杠杆松开让 Faro 接手，再拉左杠杆**融化灰尘。

### 曲柄谜题
推重物到杠杆造光罩 → 拉杠杆转光到第 2 曲柄 → 转曲柄到底。

### 最后的透镜
站电梯等 Faro 抬起，蹲行躲石化敌人，用球烧链上灰尘，推曲柄到底。
