第 5 章四符号试炼中的雕像门谜题，共三次试炼。

## Quick Solution

每次站到屋顶光柱照到的地板盘，用球三色光对齐门上宝石：

1. **第 1 次**：红 = 左雕像头盔 / 绿 = 中 / 蓝 = 右雕像手
2. **第 2 次**：绿 = 顶 / 蓝 = 底 / 红 = 右雕像眼
3. **第 3 次**：先照前右灰尘露齿轮，用齿轮让 Leni 顶住，跳台后对齐右墙

## 详细说明

- 三次试炼的套路一致：站地板盘 → 切三色光 → 旋转对齐宝石
- 第 3 次多了「先烧灰尘露齿轮」的前置步骤，别漏
- 每次对齐后要**助跑跳越尖刺**（先按住跑再跳）

> 失败原因：第 3 次没先烧灰尘露齿轮就急着对光。先照前右灰尘，齿轮出来让 Leni 顶住，再走。
