本作没有职业系统，Build 就是「技能加点顺序 × 武器 × 护符」的组合。三条主流路线如下，选一条照着配。

## 路线一：均衡流（推荐新手）

**技能顺序**：Aegean Deflect（点满红攻招架精通）→ Hero's Step → Echo's Return → Bullbreaker Kick / Fated Cast

- **武器**：Falchion 弯刀（暴击后伤害）或 Kopis 反刃刀（连段眩晕）
- **护符**：Beads（减弓箭手命中）+ Arm Bands（扩大招架窗口）
- **适合**：第一次玩、想稳扎稳打的玩家

## 路线二：招架流（激进）

**技能顺序**：Aegean Deflect → Echo's Return → Hero's Step → Bullbreaker Kick

- **武器**：**Xiphos 双刃剑**（Parry Break 招架眩晕大增，代价无法格挡）+ Khopesh 镰状剑打 Boss
- **护符**：Arm Bands（扩大招架窗口，核心）
- **适合**：喜欢高风险高回报、招架熟练的玩家

## 路线三：闪避流（稳健）

**技能顺序**：Hero's Step → Echo's Return → Aegean Deflect → Fated Cast

- **武器**：Sica 短剑（Focus Rush 击杀回专注槽）
- **护符**：Pierced Coins（专注槽概率保留充能）+ Trinkets（概率免疫致命一击）
- **适合**：喜欢拉扯、专注技连发的玩家

## 三条路线速查

| 路线 | 核心技能 | 主武器 | 思路 |
|---|---|---|---|
| 均衡流 | Aegean Deflect + Hero's Step | Falchion / Kopis | 招架→眩晕→踢击输出 |
| 招架流 | Aegean Deflect + Echo's Return | Xiphos | 完美招架→眩晕翻倍→抓人掷群 |
| 闪避流 | Hero's Step + Echo's Return | Sica | 二段闪避拉扯→专注技连发 |

## 关键提醒

- 随时**免费洗点**，三条路线可以都试试，找到手感再定
- ⚠️ 操控忒修斯 Theseus 的闪回战斗里，**Sophia 的技能升级不继承**，红攻招架不可用，先闪避适应节奏
- 招架流拿 Xiphos 后**无法格挡**，只能靠招架，手残慎用
